# Visual Direction — AI for Teachers

## Core Visual Identity

### Brand Metaphor
**The Coach, Not the Crutch.** Every visual choice should communicate warmth, competence, and empowerment. Skippy is a guide standing beside the teacher, not a machine doing the work. Avoid imagery that positions AI as futuristic, robotic, or replacing humans.

### Tone
- Professional but approachable (think: TED talk, not corporate keynote)
- Confident without being flashy
- Education-first, tech-second
- Warm, not cold; human, not machine

## Color Palette

### Primary Colors
Based on the existing design system (teal-based, shifted from original dark blue):

| Color | Hex | Usage |
|-------|-----|-------|
| **Teal** (Primary) | `#0D9488` | Primary actions, headings, key data points |
| **Teal Dark** | `#0F766E` | Hover states, emphasis |
| **Teal Light** | `#99F6E4` | Backgrounds, highlights, progress indicators |
| **Slate** | `#1E293B` | Body text, dark backgrounds |
| **Slate Light** | `#64748B` | Secondary text, captions |
| **White** | `#FFFFFF` | Card backgrounds, clean space |

### Accent Colors (for charts/data)
| Color | Hex | Usage |
|-------|-----|-------|
| **Amber** | `#F59E0B` | Warning, attention, Week highlights |
| **Emerald** | `#10B981` | Success, completion, growth |
| **Rose** | `#F43F5E` | Problems, pain points, cost comparisons |
| **Indigo** | `#6366F1` | Learning science, SOLO taxonomy levels |

### Pitch Deck Background Strategy
- **Dark slides** (Slate `#1E293B`): Hook, problem, emotional moments, closing
- **Light slides** (White/light gray): Data, how-it-works, comparisons, team
- **Teal accent slides**: Solution reveal, key differentiators
- Maintain high contrast for readability — never use medium tones for backgrounds

## Typography

### For Decks (Google Slides / Keynote)
- **Headlines:** Inter Bold, 36-48pt — clean, modern, authoritative
- **Body:** Inter Regular, 18-24pt — readable at distance
- **Data/Stats:** Inter Black, 60-72pt — big numbers that land
- **Quotes:** Inter Light Italic, 24-32pt — set apart from data
- **Fallback:** System sans-serif (SF Pro on Mac, Segoe on Windows)

### For Print Materials (One-Pager, Exec Summary)
- **Headlines:** Inter Semi-Bold, 14-18pt
- **Body:** Inter Regular, 10-11pt, 1.5 line height
- **Captions:** Inter Light, 9pt

## Imagery & Photography

### Do Use
- **Real classroom photos** — diverse teachers actively working (not posed)
- **Over-the-shoulder shots** — teacher looking at a screen with Skippy conversation visible
- **Artifact close-ups** — a prompt template printed and annotated by hand
- **Warm lighting** — natural light, classroom settings
- **Hands-on imagery** — typing, writing, discussing with colleagues
- **Diverse representation** — varied ages, ethnicities, school settings, grade levels

### Don't Use
- Stock photos of robots, circuit boards, or "AI" text overlays
- Futuristic/sci-fi imagery
- Photos of students (we serve teachers, not students)
- Cold corporate imagery (glass offices, suits)
- Overly polished / "perfect classroom" shots — authenticity matters
- Blue-tinted tech photography

### Illustration Style (If Needed)
- Simple line illustrations with teal accents
- Flat, minimal — not 3D or glossy
- Human figures should be warm and recognizable (not abstract blobs)
- Use illustration sparingly — photos and data should dominate

## Chart & Data Visualization

### Principles
1. **One point per chart.** Every chart should answer exactly one question. If it takes more than 3 seconds to read, simplify.
2. **Label directly.** No legends — label data directly on the chart.
3. **Use color intentionally.** Teal for "us" / the positive case. Rose for the problem. Gray for everything else.
4. **Animate builds.** In live presentations, reveal data points sequentially to control the narrative.

### Recommended Chart Types

| Data Type | Chart Type | Example |
|-----------|-----------|---------|
| Cost comparison | Horizontal bar chart | Skippy ($5) vs. Traditional PD ($200) — same axis, dramatic difference |
| SOLO progression | Stacked area or step chart | Pre → Uni → Multi → Relational → Extended over 7 weeks |
| Feature comparison | Matrix / checkmark table | Skippy vs. Khanmigo vs. MagicSchool vs. ChatGPT |
| Market sizing | Concentric circles or funnel | Total teachers → PD budget → AI PD gap → Our market |
| Timeline / roadmap | Horizontal timeline with milestones | Now → 3mo → 6mo → 12mo |
| Course structure | Journey map / pathway | Week 0-6 with artifact icons |

### Chart Styling
- Rounded corners on bars (4px radius)
- No gridlines — clean backgrounds only
- Teal for primary data, Slate for secondary
- Minimum 18pt font in all chart labels
- Never use 3D effects, shadows, or gradients on charts

## Screenshot Selection & Annotation

### Which Screens to Screenshot
1. **Onboarding flow** — the 3-step profile form (shows personalization)
2. **Week conversation** — mid-exchange showing Skippy's adaptive response (shows the product in action)
3. **Artifact extraction** — the moment an artifact is saved (shows concrete output)
4. **Dashboard** — progress cards and artifact gallery (shows the portfolio)
5. **Podcast player** — (optional) shows the "recap" feature

### Annotation Style
- Use teal callout boxes with white text
- Rounded rectangle callouts with arrows pointing to the relevant UI element
- Max 3 annotations per screenshot
- Annotations should highlight: personalization, adaptive response, or artifact output
- Example annotations:
  - "Adapts to 8th grade science teacher's context"
  - "SOLO level: Relational — peer-mode discourse"
  - "Artifact saved to gallery automatically"

### Screenshot Treatment
- Drop shadow (subtle, 4px blur, 10% opacity)
- Rounded corners (12px radius) on screenshot container
- Place on solid background (white or slate) — never on a photo
- Scale to fit slide without distortion — landscape screenshots work best
- Ensure real (or realistic) content is visible — not Lorem Ipsum or test data

## Slide Design Patterns

### The Big Number Slide
```
[Large stat: 72pt, Teal or White depending on background]
[One-line context: 24pt, lighter weight]
[Source: 12pt, bottom right, gray]
```
Use for: $5 per teacher, 82% unprepared, 3.7M teachers, 10-40x cost advantage

### The Comparison Slide
```
Two columns. Left: "The old way" (rose tint). Right: "The new way" (teal tint).
3-4 bullet points each. Icon or emoji per point.
```
Use for: Capacity vs. dependency, Skippy vs. traditional PD

### The Quote Slide
```
[Dark background]
"Quote text in italic, 28-32pt, white"
— Attribution, 18pt, teal
```
Use for: "I think the question isn't whether you can use AI..." and the Ozempic framing

### The Journey Slide
```
Horizontal timeline with 7 stops (Week 0-6).
Each stop has: week title + artifact icon.
Currently active week highlighted in teal; future weeks in gray.
```
Use for: The 7-week curriculum overview

### The Matrix Slide
```
Clean table with alternating row colors (white / light gray).
Checkmarks in teal. X marks in rose. Dashes in gray.
Our column highlighted with teal header background.
```
Use for: Competitive comparison

## Brand Do's and Don'ts

### Do
- Lead with the teacher's experience, not the technology
- Show artifacts — the concrete things teachers build
- Use data to support claims (cite sources)
- Keep slides clean — generous white space
- Use the teacher's voice (quotes, testimonials) when available
- Reference learning science by name (SOLO taxonomy, 4C Framework)
- Show diverse teachers in diverse school settings

### Don't
- Use the word "disrupt" (we're building *with* the education system, not against it)
- Show AI as a replacement for teachers (ever)
- Use jargon without explanation on non-technical slides
- Put more than 6 bullet points on any slide
- Use animations that distract from content
- Include student faces or names in any materials
- Promise outcomes without evidence (say "designed to" not "proven to" until pilot data exists)
- Use the phrase "AI-powered" as a selling point — the pedagogy is the selling point
- Show empty states or error screens in screenshots

- US Letter, 2 pages
- Same styling as one-pager
- Page numbers bottom-center
- Section headers in teal with horizontal rule below
