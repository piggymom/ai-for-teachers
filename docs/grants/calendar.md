- [ ] Email ISTE partnership inquiry with product demo
- [ ] Research fiscal sponsors (get quotes from 2-3)

### Month 2 (April 2026)
- [ ] Secure fiscal sponsor
- [ ] Begin university partnership conversations
- [ ] Check EIR program status and identify LEA partner if active
- [ ] Apply to Camelback Ventures if eligible

### Month 3 (May 2026)
- [ ] Apply to NYCT if competitive round is open

### Months 4-6 (June - August 2026)
- [ ] Develop NSF ITEST proposal with university partner
- [ ] Continue pilot, collecting data
- [ ] Present at ISTE conference if accepted

### Months 7-9 (September - November 2026)
- [ ] Submit NSF DRK-12 or ITEST proposal
- [ ] Compile pilot results
- [ ] Apply to Overdeck Family Foundation with pilot data

### Months 10-12 (December 2026 - February 2027)
- [ ] Publish pilot results
- [ ] Approach Hewlett, Carnegie via LOI
- [ ] Apply to Robin Hood with NYC pilot data
- [ ] Plan Year 2 expansion based on funding secured
